## Дополнения [вне лекций] — из общих знаний, на слайдах нет
> На КР ставить в ответ **после** формулировки лектора, как «пояснение». Если в вопросе есть формулировка со слайда, её главная.

### Режимы и запасы
- **Коэффициент газоотдачи (КИГ)** = извлекаемые / геологические запасы. При газовом режиме обычно высокий (≈ 0,85–0,95). При водонапорном ниже (≈ 0,6–0,8): вода «защемляет» газ в порах.
- **Почему при газовом режиме P/z линейна от Qдоб:** из материального баланса для постоянного порового объёма: P/z = (Pн/zн)·(1 − Qдоб/Qзап). Экстраполяция прямой к P/z = 0 даёт начальные запасы (графический вариант МПД).
- **Пьезометрические скважины** — в водоносной части, по ним следят за давлением/уровнем воды (признак вторжения воды). **Наблюдательные** — для контроля ГВК, насыщенности (ГИС).

### Свойства газа
- **Нормальные условия**: 0 °C, 0,1013 МПа (22,41 л/моль). **Стандартные условия** в газовой отрасли РФ: 20 °C, 0,1013 МПа (24,04 л/моль).
- **Критические параметры метана**: Tкр ≈ 190,6 К (−82,6 °C), Pкр ≈ 4,6 МПа. Метан при пластовых T всегда сверхкритичен (не сжижается давлением).
- **Крикондебар / крикондентерма**: максимальное давление и максимальная температура, при которых ещё могут сосуществовать две фазы. Ретроградная конденсация идёт между критической точкой и крикондентермой.
- **Ингибиторы гидратов**: метанол (чаще всего), гликоли (ДЭГ, ТЭГ), растворы CaCl₂. Механизм: снижают активность воды, и равновесная T гидратообразования падает.

### Скважины и ГДИ
- **Двучленный закон**: aQ — потери по закону Дарси (вязкостное сопротивление), bQ² — инерционные (турбулентные) потери, растут при больших дебитах. Линейный закон фильтрации = когда bQ² ≪ aQ (основа «энергосберегающего режима», Л06 стр. 8).
- **Абсолютно свободный дебит**: теоретический дебит при давлении на забое 0,1 МПа. Из двучлена: Q_абс = [−a + √(a² + 4b(p²пл − 0,1²))]/(2b). **Свободный дебит**: дебит при атмосферном давлении на устье (выпуск в атмосферу).
- **КВД**: по наклону прямолинейного участка p² от lg t определяют гидропроводность kh/μ, по отрезку — пьезопроводность и скин. **Гидропроводность** = kh/μ; **проводимость** = kh; **пьезопроводность** χ = k/(μ·m·β*): скорость перераспределения давления.
- **ДИКТ**: работает в режиме критического (звукового) истечения. Расход тогда зависит только от давления перед диафрагмой и её диаметра, а не от давления за ней.
- **Глушение скважины**: замещение газа в стволе жидкостью такой плотности, чтобы гидростатика ≥ пластового давления (для ремонта).
- **Направление**: короткая колонна, перекрывает неустойчивые верхние отложения. **Кондуктор**: перекрывает верхние водоносные горизонты (защита пресных вод), на нём ставят ПВО. **Эксплуатационная колонна**: канал для подъёма продукции, разобщает пласты. **НКТ (лифт)**: трубы, по которым газ поднимается внутри ЭК.

### Технологический режим и проектирование
- **ДКС** (дожимная компрессорная станция): вводится, когда пластовое давление упало и устьевого давления не хватает для подачи газа в систему сбора и на УКПГ. Отсюда режим P_у = const при задержке ввода ДКС.
- **УКПГ** (установка комплексной подготовки газа): осушка (абсорбция гликолями / низкотемпературная сепарация), отделение конденсата и воды, доведение до товарной кондиции.
- **Периоды разработки газового м-ния**: нарастающей добычи, постоянной добычи (полка), падающей добычи, завершающий. Четыре уравнения (Л05 стр. 37) решают именно для периода постоянной добычи.
- **Сайклинг-процесс**: закачка сухого газа обратно в ГК пласт для поддержания давления выше давления начала конденсации (это и есть «методы поддержания давления на ГК м-ниях», Л01 стр. 27). Подробно будет в КР-2 (лекция 9).
- **ЧДД (NPV)**: сумма дисконтированных денежных потоков за срок проекта; вариант с максимальным ЧДД при приемлемом КИГ/КИК обычно рекомендуемый.
